## SmartFood

**Red social y plataforma web para restaurantes y negocios de comida**

SmartFood es una red social moderna enfocada en conectar restaurantes, negocios de comida y comensales tanto como para restaurantes como para darse a conocer a los clientes. Ofrece una plataforma interactiva con panel de administración para gestionar menús, promociones y crear comunidad. Todo el entorno está optimizado y preparado para su despliegue mediante contenedores Docker, facilitando su escalabilidad.

---

## Características principales

- **Red social gastronómica** diseñada para conectar a los restaurantes con su audiencia.
- **Panel de administración** para gestionar platillos y menús.
- **Galería de platillos** con imágenes optimizadas.
- **Sistema de ordenamiento** de platillos.
- **Implementacion de WhatsApp y Instagram** para pedidos directos.
- **Soporte para tema claro/oscuro**.
- **Base de datos Supabase** para gestión de datos.
- **Optimización de imágenes** con Cloudinary.
- **Despliegue y escalabilidad** asegurados gracias a la implementación con contenedores Docker.

---

## Tecnologías utilizadas

- Next.js (React)
