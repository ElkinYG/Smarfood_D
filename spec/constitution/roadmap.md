# Roadmap

Orden y estado de las features de SmartFood. Este documento se actualizará conforme cada funcionalidad tenga una especificación, un plan y tareas ejecutables.

## Hecho

- Aún no hay features documentadas como completadas.

## Siguiente 🔜

- Definir la primera feature priorizada y documentarla en `features/NNN-nombre-feature/`.

## Backlog / ideas 

- **Perfil del negocio** — mostrar información, ubicación, redes sociales y datos de contacto del restaurante.
- **Gestión de menús y platillos** — crear, editar y ordenar la oferta gastronómica desde el panel de administración.
- **Galería de platillos** — publicar imágenes optimizadas mediante Cloudinary.
- **Promociones** — comunicar ofertas y novedades a la comunidad.
- **Integración de contacto** — dirigir pedidos y consultas hacia WhatsApp e Instagram.
- **Preferencia de tema** — permitir alternar entre tema claro y oscuro.

> Cada feature nueva se crea como `features/NNN-nombre-feature/` con `spec.md`, `plan.md` y `tasks.md` antes de tocar código.
